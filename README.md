# Tetris

เกม Tetris บนเว็บ เขียนด้วย HTML/CSS/JavaScript ในไฟล์เดียว เล่นได้ทั้งบนคอมพิวเตอร์และมือถือ

## เล่นออนไลน์

👉 https://ppptkpb-alt.github.io/Tetris/

## ปุ่มควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| ← → | เลื่อน |
| ↓ | Soft drop |
| Space | Hard drop |
| ↑ / X | หมุนตามเข็ม |
| Z | หมุนทวนเข็ม |
| C / Shift | Hold |
| P / Esc | หยุด |
| R | เริ่มใหม่ |
| M / N | เปิด-ปิดเพลง / เสียง |

บนมือถือใช้ปุ่มสัมผัสบนหน้าจอ

## เล่นในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม
